# Kararsız Merhaba Dünyası

## Bu Repo Nedir?

Bu, dünyanın **en kararsız** Hello World programıdır.

Diğer Hello World'ler hemen "Merhaba Dünya!" der. Bu ise:

- Önce 47 farklı şekilde düşünür
- Sonra vazgeçer
- Sonra tekrar düşünür
- Çay içer
- "Aslında merhaba demesem de olur" der
- Biraz daha düşünür
- Ve bazen, çok nadiren, gerçekten merhaba der

**Bu program üretken değildir. Bu program varoluşsal bir krizdir.**

## Nasıl Çalıştırılır?

```bash
python kararsiz.py
```

Eğer çalıştırırsan, program seni de kararsız yapabilir. Sorumluluk kabul etmiyorum.

## Özellikler

- Gerçekten çalışır
- Gerçekten hiçbir işe yaramaz
- Türkçe düşünür
- Bazen sonsuz döngüye girer (ama çıkabilir, belki)
- Copilot bile bu kodu görünce "sen çok mu yorgunsun?" diye soruyor

## Katkıda Bulunma

Lütfen katkıda bulunma. Zaten yeterince kararsız.
